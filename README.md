## ✨ 精选项目

### 🎙️ [voice-call](https://github.com/crease123/voice-call) ![stars](https://img.shields.io/github/stars/crease123/voice-call?style=flat-square&label=stars&color=yellow)

在 DSH 对话里直接开口说话，Agent 用语音回复。保留你原有的模型、工具与权限，不用另开一套 Agent。
`TypeScript` · `DSH 插件` · [📺 使用教学](https://www.bilibili.com/video/BV1t9sJ6NErV/)

### 🗓️ [dsh-journal-calendar](https://github.com/crease123/dsh-journal-calendar) ![stars](https://img.shields.io/github/stars/crease123/dsh-journal-calendar?style=flat-square&label=stars&color=yellow)

Agent 自己记日记：每天写一个 JSON，侧边栏把它画成可勾选待办的日历。
`TypeScript` · `DSH 插件` · [📺 插件教学](https://www.bilibili.com/video/BV1jQsN6gEhQ/)

### 🕵️ [Undercover](https://github.com/crease123/Undercover)

用「谁是卧底」这个游戏，探索自进化多智能体的基本机制。
`Python`

### 🧪 [superagent-playground](https://github.com/crease123/superagent-playground)

动手学习 DSH Superagent：从 GitHub 事件到任务执行与 PR 的练习项目。
`JavaScript`
